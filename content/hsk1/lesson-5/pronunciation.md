# 第五课 拼音 - Lesson 5 Pronunciation
## 她女儿今年二十岁。 - Her Daughter Is Twenty Years Old This Year.

### Erhua (儿化音)

In Chinese, 儿 (ér) can combine with the preceding syllable to form a single syllable called “erhua”. In writing: character + 儿. In pinyin: add “r” after the final.

**Examples:**

| Characters | Pinyin | Meaning |
|------------|--------|--------|
| 小孩儿 | xiǎoháir | child |
| 小鸟儿 | xiǎoniǎor | little bird |
| 饭馆儿 | fànguǎnr | restaurant |
| 香水儿 | xiāngshuǐr | perfume |

### Finals Starting with i, u, ü

Pay attention to the difference in pronunciation when these medials are present or absent:

**Finals with i:**

| Without i | With i |
|-----------|--------|
| a | ia |
| e | ie |
| ao | iao |
| ou | iou (iu) |
| an | ian |
| ang | iang |
| ong | iong |

**Finals with u:**

| Without u | With u |
|-----------|--------|
| a | ua |
| ai | uai |
| ei | uei (ui) |
| an | uan |
| en | uen (un) |
| ang | uang |
| eng | ueng |

**Finals with ü:**

| Without ü | With ü |
|-----------|--------|
| e | üe |
| an | üan |
| en | ün |

### Aspirated vs. Unaspirated Initials

Chinese initials come in aspirated and unaspirated pairs:

| Unaspirated | Aspirated |
|-------------|----------|
| b | p |
| d | t |
| g | k |
| j | q |
| z | c |
| zh | ch |

In each pair, the first is unaspirated (no puff of air), and the second is aspirated (strong puff of air).

**Practice Pairs:**

| | | | |
|---|---|---|---|
| bàng — pàng | dù — tù | gǒu — kǒu | |
| jī — qī | zì — cì | zhuō — chē | |

### Pinyin Rules (4): The Apostrophe

When a syllable starting with a, o, or e follows another syllable, an apostrophe (‘) is used to separate them and avoid confusion.

**Examples:**

| Without ‘ | With ‘ |
|-----------|--------|
| piāo (to float) | pí’ǎo (leather coat) |
| jiē (to receive) | jī’è (hungry) |
| fànàn (revolt) | fàn’àn (set meal) |
| xiān (first) | Xī’ān (Xi’an city) |
| jiāng (river) | jī’áng (excited) |
| fǎngǎn (feeling) | fāng’àn (plan) |
